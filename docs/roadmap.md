# Aplomo System: hoja de ruta de documentación

Propuesta para mantener una presentación útil y verificable. No representa un calendario de desarrollo ni certifica funciones disponibles.

## Punto de partida

Proyecto industrial contratado · febrero–julio de 2026.

## Próximos entregables públicos

- Documentar un recorrido anonimizado únicamente con permiso del responsable del proyecto.
- Organizar evidencia autorizada de flujo, mapas y trazabilidad.
- Definir cómo presentar módulos sin revelar procesos ni datos del cliente.

## Criterios de aceptación

- Ejemplos, si se incorporan, son ficticios o anonimizados y autorizados.
- Cada recorrido representa el flujo operativo comunicado por el proyecto.
- Tecnologías, premio y participación coinciden con la ficha pública.
- Enlaces locales, SVG y JSON pasan validación antes de publicación.
- Capturas o demostraciones solo se incorporan si tienen autorización de publicación.

## Actualización de estado

Para cambiar el estado público: describir qué cambió, aportar una referencia revisable, indicar limitaciones y obtener validación del responsable del producto. Evitar convertir planes en afirmaciones de resultados.
